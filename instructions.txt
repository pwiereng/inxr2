# Issue #177: MCP (Model Context Protocol) interface for querying INXR2

## Summary

Build an MCP server that exposes INXR2's code intelligence as tools for AI assistants
(Claude, Cursor, etc.). The server is a thin HTTP wrapper around INXR2's existing FastAPI
endpoints, translating MCP tool calls into API requests and formatting responses for AI
consumption.

## v1 Scope: 4 High-Value Tools

Only implement these 4 tools for v1. These are INXR2's unique strengths that AI agents
can't easily replicate with local tools (grep, git):

### 1. `find_references`
Find all usages of a symbol across all indexed repos.
- Parameters: `name` (required), `repository?`, `ref_type?` (import/call/usage/type_annotation)
- Backend flow:
  1. `GET /api/symbols?q={name}` to find matching symbols
  2. `GET /api/symbols/{id}/references?by_name=true` for cross-repo references
- This is the killer feature — tracing usages across 12+ repos with semantic awareness.

### 2. `go_to_definition`
Jump to the definition of a symbol (works cross-repo).
- Parameters: `name` (required), `repository?`, `file_path?`
- Backend: `GET /api/symbols/by-name/{name}?repository_id={id}`
- Returns: file path, line number, repository, signature, docstring

### 3. `search_symbols`
Find symbol definitions by name (semantic, not text).
- Parameters: `query` (required), `repository?`, `kind?` (function/class/variable), `limit?`
- Backend: `GET /api/symbols?q={query}&kind={kind}&repository_id={id}&limit={limit}`
- Filterable by kind and language, across all repos.

### 4. `search_code`
Full-text/regex search across all indexed repos.
- Parameters: `query` (required), `repository?`, `mode?` (keyword/regex/phrase), `extensions?`
- Backend: `GET /api/search/text?q={query}&mode={mode}&repo={repo}&extensions={ext}`

## Architecture

```
AI Assistant (Claude/Cursor)
    ↓ MCP protocol (stdio or SSE)
MCP Server (Python, mcp-server/)
    ↓ HTTP requests
INXR2 API (FastAPI, port 8000)
    ↓ SQL
PostgreSQL
```

The MCP server does NOT access the database directly. It calls INXR2's existing HTTP API.
This keeps it decoupled and means any API improvement automatically benefits MCP users.

## Existing API Endpoints to Wrap

### Symbols (`/api/symbols`)
- `GET /api/symbols` — search by name with filters (q, kind, repository_id, branch, language, extensions, limit, offset)
- `GET /api/symbols/by-name/{name}` — exact name match (repository_id, commit)
- `GET /api/symbols/{symbol_id}` — get symbol details
- `GET /api/symbols/{symbol_id}/references` — all references (by_name, commit, branch, limit)

### Search (`/api/search`)
- `GET /api/search/text` — full-text/regex search (q, mode, repo, branch, extensions, case_sensitive, limit, offset)

### Repositories (`/api/repositories`)
- `GET /api/repositories` — list all repos
- `GET /api/repositories/by-name/{name}` — get repo by name

### Files (`/api/files`)
- `GET /api/files/by-path` — get file content (repo, path, commit, branch)

## Response Format

Optimize for AI consumption — structured, concise, no HTML:

```json
// find_references("DatabaseConnection")
{
  "symbol": "DatabaseConnection",
  "references": [
    {
      "file": "src/inxr2/adapters/cli/commands/index_command.py",
      "line": 25,
      "type": "import",
      "repository": "inxr2",
      "context": "from inxr2.infrastructure.database.connection import DatabaseConnection"
    }
  ],
  "total": 1
}
```

## Docker Integration

Add an MCP service to `docker-compose.dev.yml` with `--profile mcp`:

```yaml
mcp:
  profiles: ["mcp"]
  build:
    context: ./mcp-server
    dockerfile: Dockerfile
  container_name: ${COMPOSE_CONTAINER_PREFIX:-inxr2}-mcp
  environment:
    - INXR2_API_URL=http://${COMPOSE_CONTAINER_PREFIX:-inxr2}-dev:8000
  ports:
    - "${MCP_PORT:-3000}:3000"
  depends_on:
    - dev
```

The MCP server should support both:
- **stdio transport** — for local use (Claude Desktop, Cursor)
- **SSE transport** — for remote/Docker use

## MCP SDK

Use the official Python MCP SDK: `mcp` (https://github.com/modelcontextprotocol/python-sdk)

```python
from mcp.server import Server
from mcp.types import Tool, TextContent

server = Server("inxr2")

@server.list_tools()
async def list_tools() -> list[Tool]:
    return [
        Tool(
            name="find_references",
            description="Find all usages of a symbol across all indexed repositories",
            inputSchema={...}
        ),
        ...
    ]

@server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[TextContent]:
    if name == "find_references":
        return await handle_find_references(arguments)
    ...
```
